# Archive — original advanced-UI / crunch-heavy design

This folder holds the first pass at Red Planet Corporate:

- `index.html`, `app.js`, `pages.js` — an interactive dashboard mockup (hex map, garrison
  management, dynamic market, subdivision equity, live standings UI).
- `mars master rulebook.xlsx` — a 24-sheet mechanical rulebook (exact building/module costs,
  per-unit action budgets, dynamic price-elasticity formulas, an equity/dividend market, a
  vehicle hull-and-module system, weighted composite scoring, probability-tabled events).
- `RULES-v1-crunch-heavy.md` — the rulebook that reconciled the above with the lore docs
  into one host-ready ruleset.

The game is now being run as a traditional NRP instead — see `../RULES.md`. That version
keeps this world's setting and corporate flavor but drops the spreadsheet-simulation layer
(per-unit action accounting, price formulas, the equity market, the vehicle mini-game) in
favor of host-adjudicated, PM-submitted turns, the way this genre is actually played.

Nothing here is deleted — if a future host wants the deeper simulation back, or wants to
mine it for specific numbers, it's all still here.
